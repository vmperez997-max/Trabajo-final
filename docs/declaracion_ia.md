# Declaración de uso de inteligencia artificial

Se utilizó asistencia de IA generativa para apoyar la organización del repositorio, redactar esqueletos de código y revisar consistencia documental. Las decisiones sobre alcance, dataset, métricas, perturbaciones, pruebas y conclusiones fueron verificadas ejecutando el código en el entorno del proyecto.

La IA no se utilizó para inventar métricas. Los valores reportados provienen de la ejecución reproducible de `scripts/run_experiment.py` y se conservan en `output/results/metrics.json`.
